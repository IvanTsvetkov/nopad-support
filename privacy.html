NoPad Privacy Policy

Last updated 2026-08-16.

Last updated: 2026-08-16

The short version

NoPad collects nothing, tracks nothing, and makes no network requests.

There is no account, no sign-in, no analytics, no crash reporting and no advertising. NoPad contains no code from any other company. Nothing you open, paste, type or format leaves your Mac.

What NoPad does with your text

Everything you put in NoPad stays on your Mac:

  • Buffers — the text in a tab — are kept in NoPad's own private folder, the one macOS gives an app for its own files and keeps other apps out of. They are written there as you type and again when you quit, which is why NoPad has no save step: nothing you have typed is waiting to be saved, and nothing is lost by closing the window or quitting.
  • Files you open stay where they are. NoPad reads a file you chose in the open panel or dropped on the window; a very large file is read in place rather than copied. It remembers where the file is so it can reopen it next time you launch the app.
  • Export is the only action that writes to a place you chose, and only when you ask it to.

How long your text is kept, and how to get rid of it

A buffer stays until you throw it away, which is the only thing that can happen to it:

  • Discard Buffer (Shift-Cmd-W) deletes that buffer's text from NoPad's folder. There is a ten-second window to undo it, after which it is gone.
  • Closing a tab (Cmd-W) does not delete anything. The buffer moves to the sidebar list and the text stays where it was; Shift-Cmd-T brings the tab back.
  • Nothing expires and there is no second copy anywhere: what the sidebar lists is everything NoPad is keeping.

Files you opened from elsewhere are never altered by any of this. Discarding a buffer that came from a file forgets where the file was; the file itself stays exactly where you left it.

Data collected

None.

NoPad does not collect your name, your email address, your location, your contacts, your browsing or search history, any identifier for you or your Mac, any record of what you do in the app, any diagnostic or crash report, or the contents of your files. None is gathered, so there is none to share.

Tracking

None. NoPad does not track you across other apps or websites and does not contact advertising or analytics companies — it has no way to; see the next section.

Network

NoPad has no networking at all. No part of the app can send or receive anything over the internet, and there is no code from anyone else inside it that could do so on its behalf. You can confirm this yourself: disconnect from the internet entirely, and every feature works exactly as it did.

Information macOS lets NoPad read

Two things, both about files rather than about you:

  • When a file was last changed. NoPad checks this so that when it reopens a file you had open before, it can tell whether the file is the same one or has been edited by something else since. It reads this only for files you chose to open. It is never shown to anyone and never leaves your Mac.
  • The size and position of NoPad's window, which macOS saves so the window comes back where you left it.

iCloud

This version does not sync. Buffers and settings stay on the Mac they were made on.

If syncing is added later it will use your own private iCloud account and nothing else; there is no server belonging to the developer and no plan for one. This policy will say so first.

Children

NoPad is a text editor. It collects no data from anyone, of any age.

Changes

If this policy changes, the new version arrives inside the app with the update, and the date at the top changes with it. The copy in NoPad always applies to the version you are running.

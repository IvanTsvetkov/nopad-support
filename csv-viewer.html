NoPad opens CSV and TSV as a table you can read and edit. It works out the delimiter from the text itself, so a pasted export or a downloaded file becomes rows and columns without an import dialog, and without a spreadsheet changing your data.

What it does with CSV

  • Shows a table. Paste or open a CSV or TSV and read it in rows and columns.
  • Edits cells on Mac. Change a value in the table on Mac, and the text underneath follows.
  • Lets you set the delimiter and header. The detected delimiter and header row can both be overridden when a file is unusual.
  • Keeps your values as they are. Quoted empty fields stay data, and a value like 007 stays 007.
  • Formats in place. Lay out a CSV or TSV as an edit you can undo.
  • Finds and compares. Search a file or every open buffer, and compare two buffers in a split diff.

On Mac, iPad and iPhone

Mac has the editable table. iPad edits the source and previews CSV and TSV as a table beside it, with the same delimiter and header controls. iPhone is a reader for buffers synced from your other devices. Sync is optional and uses your own private iCloud storage.

Questions

Is NoPad free?

Yes. NoPad is free on the App Store, with no subscription and no in-app purchases.

Does it change my original file?

No. Opening a file imports it as a buffer, and Export writes a copy only when you choose to.

Can it open a very large CSV?

On Mac, NoPad opens multi-gigabyte files by mapping them instead of loading them whole, so a large file can be read and searched. Table view has a limit on large inputs and falls back to the source view when it reaches it.

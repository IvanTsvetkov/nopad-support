NoPad Support

A scratch editor for structured text, for macOS.

NoPad is a scratch editor for structured text on macOS. Paste JSON, CSV, YAML, SQL or a log into it and it works out what the text is from its content and formats it. There is no save step, no account and no network.

Getting help

Write to ivanscvetkovs@icloud.com. That address reaches the person who wrote the app. Include your macOS version and, if something went wrong, what you were doing when it did.

Questions that come up

Where is my text? I never saved it.

It is kept. Every buffer is written to NoPad's own private storage as you type and again when you quit, so it is there when you come back, including after a restart. That is why there is no save step and no prompt when you close a tab. Pressing ⌘S confirms it.

How do I get a file out of NoPad?

⇧⌘E exports the buffer to a location you choose. It is the only action that writes anywhere outside NoPad's own storage.

How do I delete a buffer?

⇧⌘W discards it, with ten seconds to undo. ⌘W only closes the tab — the buffer stays in the sidebar and ⇧⌘T brings it back.

It opened my file in a mode I did not expect.

NoPad reads content, not file extensions: a .txt full of JSON is treated as JSON, and a CSV opens in the table view. Files over the large-file threshold open mapped, with highlighting and the minimap off — that is deliberate, not a fault. The format can be overridden from the status bar.

Does it send anything anywhere?

No. There is no networking code in the app at all. Disconnect from the internet entirely and every feature works exactly as it did. The full privacy policy is inside the app, under About NoPad, and on this site.

Does it sync between Macs?

Not in this version. Buffers and settings stay on the Mac they were made on.

Reporting a bug

Email the address above. What helps most: what you pasted or opened (or its shape, if it is private — never send anything confidential), what you expected, and what happened instead.
